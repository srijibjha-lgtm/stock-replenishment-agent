# Annapurna Mart · replenishment settings (sample)

- Weekly purchasing budget: Rs 1,50,000
- Review period: 7 days (we order once a week, every Monday)
- Target service level: 95% for class A items, 90% for B, 85% for C
- Purchase orders under Rs 5,000 per supplier are approved automatically by policy.
- Larger orders need the store manager's approval.
- Never order more than the item can sell before its shelf life ends.
